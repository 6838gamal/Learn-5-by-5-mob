# Learn 5 by 5

A Flutter "Hello World" starter project, originally created with [FlutLab](https://flutlab.io) and imported from GitHub.

## Stack
- **Framework:** Flutter (Dart SDK ^3.0.0)
- **Targets:** Android, iOS, Web

## Project structure
- `lib/main.dart` — app entry point (single Hello World screen)
- `pubspec.yaml` — Flutter dependencies
- `android/` — Android platform files
- `ios/` — iOS platform files
- `web/` — Flutter web assets

## Notes
- Mobile builds (Android/iOS) require platform SDKs not available on Replit.
- Flutter web can be enabled and run on Replit with additional setup.
- No external secrets or services are required by the current code.
